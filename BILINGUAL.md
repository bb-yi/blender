# Bilingual Documentation Setup Guide

This document explains how the dual Chinese-English documentation system works.

## Directory Structure

```
docs/
├── en/                              # English documentation
│   ├── index.md                    # English homepage
│   ├── 1_scene_level_extension.md
│   ├── 2_extended_nodes.md
│   ├── 3_npr_tree_workflow.md
│   ├── 4_interface_workflow.md
│   └── images/                     # Shared image files
│
├── zh/                              # Chinese documentation
│   ├── index.md                    # Chinese homepage
│   ├── 1_scene_level_extension.md
│   ├── 2_extended_nodes.md
│   ├── 3_npr_tree_workflow.md
│   ├── 4_interface_workflow.md
│   └── images/                     # Same images (shared reference)
│
└── images/                          # Original images (can be removed)
```

## Navigation Structure

The website features a dual-language navigation system:

### Default (English)
- Home
- Documentation
  - Scene Extensions
  - Extended Nodes
  - NPR Tree Workflow
  - Interface Guide

### Chinese Section
- 中文 | Chinese (submenu)
  - 首页
  - 文档
    - Scene 级 Eevee 扩展
    - 主要扩展节点
    - NPR Tree 工作流
    - 界面与工作流补充

## How It Works

### Navigation Tabs
The top navigation displays both English and Chinese sections as tabs:
- **English tab** shows English documentation
- **Chinese tab** (中文) shows Chinese documentation

### Independent Trees
- English documentation is completely separate from Chinese
- Each language has its own index and page structure
- Both versions use the same image assets to save storage space

## Deployment

The multi-language documentation deploys as a single site with both languages accessible:

```
https://bb-yi.github.io/blender/              # English homepage
https://bb-yi.github.io/blender/zh/           # Chinese homepage
```

## Adding New Pages

To add a new page in both languages:

1. Create English version: `docs/en/page_name.md`
2. Create Chinese version: `docs/zh/page_name.md`
3. Update `mkdocs.yml` navigation:
```yaml
nav:
    - Home: index.md
    - Documentation:
        - New Page: page_name.md
    - 中文 | Chinese:
        - 首页: zh/index.md
        - 文档:
            - 新页面: zh/page_name.md
```

## Managing Images

### Current Approach
- Images are stored in both `docs/en/images/` and `docs/zh/images/`
- This is redundant but ensures both versions work independently
- Both can be deleted/re-copied as needed

### Optimize Storage (Optional)
To reduce storage, delete one copy:
```powershell
Remove-Item docs/images/ -Recurse -Force
```

The site will still function correctly as each language directory has its own image folder.

## Translation Workflow

### For Content Updates

1. **Update English first:**
   ```
   docs/en/2_extended_nodes.md
   ```

2. **Translate to Chinese:**
   - Maintain same structure as English version
   - Keep same heading levels and formatting
   - Save to `docs/zh/2_extended_nodes.md`

3. **Update mkdocs.yml** if navigation structure changed

4. **Commit and deploy:**
   ```powershell
   git add .
   git commit -m "Update: English and Chinese docs"
   mkdocs gh-deploy
   ```

### Translation Tips

- Keep technical terms consistent between versions
- Use simplified Chinese (中文) for broader accessibility
- Maintain heading hierarchy for proper TOC generation
- Test both versions locally before pushing:
  ```powershell
  mkdocs serve
  ```

## Building & Testing

Then visit:
- English: http://localhost:8000

### Build for deployment:

```powershell

mkdocs gh-deploy
```

## Configuration Details

The `mkdocs.yml` configuration enables bilingual support through:

- **Two separate navigation trees** under `nav:`
- **language: en** sets primary interface language to English
- **extra.alternate** section lists available languages
- Each language has its own directory tree

## Search Functionality

The search feature works across all pages:
- English search indexes English documentation
- Navigate to Chinese section to search Chinese docs
- Search results link to correct language version
