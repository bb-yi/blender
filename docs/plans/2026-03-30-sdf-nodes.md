# SDF Nodes Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add Goo Engine compatible `Sdf Primitive` and `Sdf Operator` shader nodes to the Blender 5.1 NPR port.

**Architecture:** The port keeps Goo's feature set and enum layout, but is implemented in the modern node style used by this branch. DNA/RNA define persistent node storage, shader node registration exposes the nodes to Blender, and GPU material shaders provide the runtime behavior.

**Tech Stack:** C++, Blender DNA/RNA, shader node registration, GLSL GPU material shaders, Python UI menu integration

---
