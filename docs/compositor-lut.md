# 合成器 LUT 调色

通过 **添加 → 颜色 → 调整 → LUT Color Grade** 创建原生节点。
选择 `.cube` 或切片图片 LUT，连接 Image，并使用 Strength 调节强度；Strength 也接受逐像素遮罩、关键帧和驱动。
Alpha 保持不变，RGB 在取消预乘后调色，再恢复预乘；强度为零和完全透明像素保持输入。

## 色彩预设

| 预设 | 行为 |
| --- | --- |
| sRGB Look | 场景工作色域 → sRGB → LUT → 场景工作色域，位于场景视图变换之前 |
| Scene Linear | LUT 的输入和输出直接使用当前场景工作色域 |
| Custom | 分别指定 LUT 预期输入、输出色彩空间，节点接口仍使用场景工作色域 |
| Raw Lookup | 不做色彩空间转换，直接查表，适合已自行配置转换的节点网络 |

`.cube` 的格式和尺寸不能可靠说明它预期的色域。相机 Log LUT 应使用匹配的自定义输入、输出色域。
有限数值范围的 LUT 可能截断超范围高光；节点遵循文件的 Domain 和 OCIO 的边界规则，
不会把任意 SDR LUT 伪装成能无损处理所有 HDR 值的变换。

高级面板提供自动、线性、四面体插值，以及正向/反向处理。
自动采用 OCIO 的最佳插值：1D 线性、3D 四面体。格式不支持所选插值时遵循 OCIO 的默认值和警告。
GPU 线性采样采用显式浮点插值，避免短 1D 表或组合 LUT 的硬件插值权重量化误差。
反向处理不能恢复已被 LUT 裁掉或合并的颜色。
自定义输入、输出色域描述 LUT 的正向编码；反向模式会自动交换这两个色域。

## 文件

文件行提供打开、重新加载、清除；文件面板提供打包、解包和相对路径。
已打包时，直接编辑路径只修改外部文件引用；打开或重新加载会替换 LUT 内容。
重新加载会更新已打包的 LUT。外部文件改变大小或修改时间后也会重新建立缓存；
同长度、同时间戳的替换应使用重新加载按钮。
文件内容以不可变快照交给 OCIO，避免同路径缓存导致重载无效。
节点打包与 **文件 → 外部数据 → 打包资源/解包资源** 集成；保存重开和节点复制保留打包内容。
单文件限制为 64 MiB，支持 `.cube` 的 1D、3D 和 OCIO 支持的组合形式。
缺失或无效文件产生节点错误和合成器提示，并保留原图输出。

## 二维切片图片 LUT

支持 PNG（8/16 位）、TIFF 和平面 EXR，直接通过节点的文件按钮打开。
自动识别横向条带、纵向条带和无间隔的切片网格，不需要手工输入尺寸。

| 图片尺寸 | 识别结果 |
| --- | --- |
| 256 × 16 | 16³，16 × 1 个切片 |
| 1024 × 32 | 32³，32 × 1 个切片 |
| 4096 × 64 | 64³，64 × 1 个切片 |
| 16 × 256 | 16³，1 × 16 个切片 |
| 256 × 128 | 32³，8 × 4 个切片 |
| 512 × 512 | 64³，8 × 8 个切片 |

每个切片为 N × N 像素，总共 N 个切片；N 支持 2 到 OCIO 上限 129。
默认从图片左上角开始，切片先向右排列再向下排列；切片内部红色轴从左到右，绿色轴从上到下，
蓝色轴随切片索引递增。高级设置的 **Flip Image Vertically** 可调整整图方向，
**Reverse Green Axis** 只反转切片内的绿色轴，保留切片排列顺序。

图片按原始数值读取，忽略表图片自身的 Alpha，不自动添加 sRGB 解码；
LUT 预期的输入、输出色域仍由节点的色彩预设决定。浮点 EXR 可保留超出 0 到 1 的表值。
读取后还原为 3D 表，并复用 OCIO 的线性/四面体插值，避免二维纹理采样跨越切片边界。
图片同样支持强度、遮罩、反向、重载、相对路径、打包及无外部文件的冷启动。

目前仅支持上述完整切片排列；带边框或间隔的图集、Hald 排列和自定义 RGB 轴置换未接入。
这些排列可能拥有相同图片尺寸，不能单靠尺寸可靠识别；Hald 图片应先转换为切片图或 `.cube`。

## 显示后调色

**Display LUT Setup (AgX)** 创建 AgX 显示转换组、可直接编辑文件的原生 LUT 节点、
以及从 sRGB 显示值回到工作色域编码的转换组。LUT 位于两个转换组之间，使用 Raw Lookup。
转换组显式处理 Alpha 预乘，原生 LUT 文件控件仍在外层可见。

添加时的 **Use Standard / sRGB Scene Output** 会把整个场景的显示设备设为 sRGB、
视图变换设为 Standard、Look 设为 None，避免重复 AgX。关闭该选项则保留场景设置，需自行配置输出。
该预设固定采用 AgX / None，场景其余曝光、Gamma、白平衡设置仍在最终输出阶段起作用；
它不承诺自动复刻所有已有场景的显示设置。转换后的 EXR 是显示参照的线性编码，
需要原始场景 HDR 数据时，应另保留显示变换之前的输出分支。

## Python 与验证

节点类型为 `CompositorNodeLUT`。常用属性为 `filepath`、`preset`、`interpolation`、`direction`、
`input_color_space`、`output_color_space` 和只读的 `is_packed`。
自定义模式默认 `use_same_color_space=True`；指定 `output_color_space` 会自动切换为独立输出色域。
输入名称为 `Image`、`Strength`；内部稳定标识分别为 `Image`、`Fac`。
文件操作支持 `bpy.ops.node.lut_file(action='PACK')` 等，需在 `bpy.context.temp_override(node=lut)` 中调用。

回归入口：`tests/python/npr/test_compositor_lut.py`，外层 Release case 为 `compositor-lut`。
测试必须使用隔离用户目录和源码树外的 `BLENDER_TEST_OUTPUT_DIR`。
