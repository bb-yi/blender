# NPR material compatibility regressions

These tests generate isolated scenes and compare rendered pixels. They cover native Cube strip sampling, free Filter Graph resolution and legacy migration, relative image cold loading, Closure captures, static macro branches, Render Info shader stages and tessellation coordinates.

`WITH_GPU_RENDER_TESTS` registers the self-contained tests in CTest for enabled OpenGL/Vulkan backends. Output and all Blender user resource directories are isolated per test. Each script can also run with `blender --background --factory-startup --gpu-backend <backend> --python <script>` after setting `BLENDER_USER_RESOURCES`, `BLENDER_USER_CONFIG`, `BLENDER_USER_SCRIPTS`, `BLENDER_USER_DATAFILES` and `BLENDER_USER_EXTENSIONS` to disposable directories. Set `BLENDER_TEST_OUTPUT_DIR` to retain generated renders and temporary blend files. Do not run factory-reset scripts against real user directories.

The Windows-only `test_filter_scale_memory.py` additionally uses PowerShell 7 and Windows GPU Process Memory counters. It runs 300 distinct sizes in one persistent offscreen viewport; separate F12 renders cannot detect this cache-lifetime regression. `test_filter_stage_pool.py` checks actual GPU texture allocation logs: stable stages must stop allocating after warmup, and removing stage outputs must release their pools.

The small `data/filter_graph_50254.blend` fixture was generated from an isolated NPR 502.54 scene. It contains a procedural Render Info filter at legacy scale 0.1, with no external assets. The new loader must preserve its effective stage-relative 1/8 scale. All other fixtures are generated by the tests, including the relative LUT file read by a fresh background child process.

Expected limitations remain explicit: Cube inputs are horizontal six-face images with generated mipmaps; Metal tessellation is not covered; advanced/unknown macro expressions are left to the backend; Tessellation Control inputs are material constants rather than dynamically evaluated links. A successful parser result does not replace GPU rendering checks.
